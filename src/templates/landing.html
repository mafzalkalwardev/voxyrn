What is Voxyrn?

Voxyrn is a self-hosted AI auto dialer and carrier CRM. Selenium places outbound calls through the operator's own Google Voice account. On Linux the browser is Chromium. On Windows it is Google Chrome. A voice agent listens and answers on the connected call. The same run can write the call log, the recording, the transcript, the lead, and the carrier profile. Speech can stay on the machine with Piper or Kokoro, faster-whisper, and a local GGUF model, or it can use Groq when an API key is configured.
